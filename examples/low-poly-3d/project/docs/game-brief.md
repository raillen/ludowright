# Copper & Forge

Copper & Forge é um protótipo low-poly 3D sobre uma mensageira que mantém uma
forja comunitária em funcionamento. O exemplo cobre uma personagem e um
edifício, sem tentar representar um jogo completo ou uma cena pronta para
engine.

## Regra visual

A personagem usa proporções consistentes, base neutra e componentes separados.
O edifício mantém massa, telhado, aberturas e estado construtivo legíveis. As
referências são guias de produção, nunca blueprints geométricos exatos.
