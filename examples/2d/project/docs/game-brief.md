# Starfall Courier

Starfall Courier é um jogo 2D de sprites sobre uma mensageira que atravessa
ruínas iluminadas por estrelas. O escopo deste exemplo é deliberadamente
pequeno: uma personagem, duas poses de produção e uma referência visual que
aguarda aprovação humana.

<!-- ludowright:asset-candidate family="character" subtype="humanoid" --> Courier

## Regra visual

A personagem deve manter silhueta legível em 256×256 pixels, fundo transparente
e escala consistente entre `idle` e `run`. O exemplo não presume reconstrução
3D nem chamada de provider.
