# Mossbridge Commons

Mossbridge Commons is a small low-poly environment built from repeatable
modules. A stone commons building anchors a courtyard, a road reaches the
entrance, and oak and field-plant references define the foliage language.
Modules must expose readable edges, sockets, clearances, and assembly states so
the same kit can support more than one composition.
