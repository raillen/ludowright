# Lantern Path

Lantern Path é um jogo 2D curto sobre atravessar um bosque durante a noite.
O jogador carrega uma única lanterna e usa sua luz para encontrar o caminho.

<!-- ludowright:asset-candidate family="prop" subtype="handheld-tool" --> Lantern

## Escopo do exemplo

O exemplo cobre uma entrada de asset, um job de referência visual, uma
aprovação humana e uma folha técnica derivada. O pacote final é criado apenas
depois que os arquivos canônicos forem validados.
